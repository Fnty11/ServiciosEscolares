# Sistema de Servicios Escolares

**Materia:** Administración de Proyectos Informáticos
**Carrera:** Licenciatura en Informática

## Descripción del Proyecto
Este repositorio contiene el código fuente y la documentación técnica para el sistema de control de Servicios Escolares. El proyecto está diseñado bajo una arquitectura de microservicios y gestionado a través de metodologías ágiles y control de versiones, implementando el enfoque de "Docs as Code" para la documentación.
